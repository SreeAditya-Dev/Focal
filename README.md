# Focal

AI-powered image quality & defect detection — a full-stack app that accepts an image and evaluates blur, exposure, noise, corruption, and visual defects using a hybrid classical-CV + CNN pipeline.

Full architecture, dataset design, model details, API, and deployment plan: see the implementation plan (built with the project). Setup/usage instructions will be filled in as each part of the stack is built.

**Stack**: React + TypeScript + TailwindCSS (frontend) · Python FastAPI (backend) · PyTorch + OpenCV/scikit-image (ML) · PostgreSQL (DB) · Docker Compose (local) · Railway + Vercel (cloud).
